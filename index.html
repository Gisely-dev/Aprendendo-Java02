O que é Java?

Java é uma linguagem de programação orientada a objetos, criada para ser usada em praticamente qualquer tipo de sistema, desde aplicativos de celular até sistemas bancários gigantescos.

O nome vem de um trocadilho com café (Java é uma ilha da Indonésia famosa pela produção de café), e não é à toa que o símbolo da linguagem é uma xícara de café fumegante ☕.

Em resumo: Java é uma linguagem de propósito geral. Ou seja, não foi feita para um único tipo de tarefa, ela serve para construir praticamente qualquer tipo de software.

Um pouco de história

Entender a origem ajuda a entender por que Java é do jeito que é hoje:

1991 a 1995: um time liderado por James Gosling, na Sun Microsystems, cria a linguagem, originalmente pensada para eletrodomésticos e dispositivos inteligentes e batizada de "Oak".
1995: a linguagem é relançada com o nome Java, focada na internet que começava a crescer.
2009: a Oracle compra a Sun Microsystems e passa a ser a responsável pelo desenvolvimento do Java.
Hoje: Java continua entre as linguagens mais usadas do mundo, com atualizações frequentes e uma comunidade enorme.

O segredo por trás do Java: a JVM

A frase mais famosa sobre Java é: "escreva uma vez, rode em qualquer lugar" (write once, run anywhere). Isso é possível graças à JVM (Java Virtual Machine).

Quando você compila um programa Java, ele não vira um executável direto do seu sistema operacional. Ele vira um bytecode, um formato intermediário. Esse bytecode roda dentro da JVM, que existe para Windows, Linux, Mac e outros sistemas.

Seu código (.java)
        ↓ compilação
    Bytecode (.class)
        ↓
  JVM (Windows / Linux / Mac)
        ↓
   Programa rodando
Por isso funciona em qualquer lugar: você compila o código Java uma vez, e o bytecode gerado roda em qualquer computador que tenha a JVM instalada, sem precisar recompilar para cada sistema operacional.

Onde Java é usado no mundo real

🏢 Sistemas corporativos Bancos, seguradoras e grandes empresas usam Java em sistemas internos e ERPs.
📱 Aplicativos Android Por muito tempo foi a linguagem oficial para apps Android, hoje divide espaço com Kotlin.
🌐 Back-end de sites e APIs Frameworks como Spring tornam Java uma escolha forte para o back-end de aplicações web.
📡 Sistemas embarcados e IoT Caixas eletrônicas, cartões inteligentes e dispositivos conectados.
📊 Big Data Ferramentas como Hadoop e Spark, usadas para processar grandes volumes de dados, são escritas em Java.

Por que Java é uma boa escolha para começar

  • Tipagem forte: ajuda a identificar erros antes mesmo de rodar o programa, o que é ótimo para quem está aprendendo lógica.
  • Base sólida em orientação a objetos: os conceitos aprendidos aqui (classes, objetos, herança) você vai usar em praticamente qualquer outra linguagem depois.
  • Mercado de trabalho: Java continua entre as linguagens mais requisitadas em vagas de desenvolvimento, especialmente em empresas de grande porte.
  • Comunidade e documentação: por ser tão usada há décadas, é fácil encontrar tutoriais, fóruns e respostas para praticamente qualquer dúvida.
Vale lembrar: Java é mais verboso que outras linguagens (você escreve mais código para fazer a mesma coisa). Isso pode parecer trabalhoso no início, mas ensina disciplina e organização que fazem diferença em projetos grandes.
