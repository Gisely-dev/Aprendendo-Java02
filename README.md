# O Que é Java e Para Que Serve?

Material didático em HTML, feito para ser lido no navegador, sobre os fundamentos da linguagem Java: o que ela é, de onde veio e onde é usada no mundo real.

## Conteúdo do arquivo

[`o-que-e-java-e-para-que-serve.html`](./o-que-e-java-e-para-que-serve.html)

O material cobre:

- **O que é Java**: definição da linguagem e origem do nome
- **Um pouco de história**: linha do tempo desde a criação até os dias de hoje
- **Características principais**: orientação a objetos, portabilidade, tipagem estática e mais
- **O segredo da JVM**: como o Java consegue rodar em qualquer sistema operacional
- **Onde Java é usado**: sistemas corporativos, aplicativos Android, back-end, IoT e Big Data
- **Por que aprender Java**: vantagens da linguagem para quem está começando

## Como usar

Basta acessar o link `https://gisely-dev.github.io/Aprendendo-Java02/` diretamente no navegador. Não é necessário nenhuma instalação ou servidor.

## Sobre

Parte da série de estudo **aprendendo-java**, material criado para consolidar o aprendizado através da escrita didática.
